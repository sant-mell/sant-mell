| Project | What it is | Built with |
|---|---|---|
| **[Rex](https://github.com/sant-mell/rex)** | A routine buddy for children with cognitive disabilities and their caregivers. **Won the Ideathon Teletón 2026 overall**, built by five of us in two days, and now under expert review with support from the Wadhwani Foundation. I built the prototype: a dependency-free Python server with one lock-guarded state machine shared by the parent panel and the device, so a parent's change reaches Rex in under a second. | `Python` `JavaScript` |
| **[DT Construct ICS](https://dtc-ingenieria.com)** | A live site for a Mexican construction company, my first paying client. Hand-coded, six service pages, interactive Leaflet maps, and a gallery of their finished work. [Source](https://github.com/sant-mell/dt-website). | `HTML` `CSS` `JavaScript` `Leaflet` |
| **[SOFIPO Savings](https://github.com/sant-mell/sofipo-savings-powerbi)** | Where should 200,000 MXN of savings go? Compares 14 options across banks, SOFIPOs, fintechs, CETES and the S&P 500, net of ISR and within deposit-protection limits. A split strategy nets about **12.4%**, against 6.3 to 8.7% for any single product. Report pages still in progress. | `Power BI` `DAX` `Python` |
| **[Breakout](https://github.com/sant-mell/myTC2005B)** | Breakout on a custom HTML5 Canvas engine, no framework. Tilt the paddle 30 degrees to aim the ball into corners. Three themed levels. | `JavaScript` `Canvas` |
| **[Portfolio](https://github.com/sant-mell/sant-mell.github.io)** | Four languages, a three.js globe and a WebGL shader background, deployed by GitHub Actions on every push. | `Next.js` `React` `TypeScript` `Tailwind` |
